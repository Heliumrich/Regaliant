# Controls

[Back to the main page](../README.md)

Xbox and other XInput controllers work like the PS5 pad, with their own button prompts. PlayStation controllers (DualSense, DualSense Edge and DUALSHOCK 4) work directly over USB or Bluetooth, without Steam Input, with the game's own button prompts, vibration and light bar. Connect controllers at any time. All connected controllers play as one pad, so Steam Input can stay on with its default layout. If you remapped buttons in Steam Input or DS4Windows, turn it off for this game: the game also reads the controller itself, so the original buttons press too.

## Keyboard and mouse

Defaults, Dark Souls III-style:

| Action | Keys |
| --- | --- |
| Move | W A S D |
| Walk | Left Alt |
| Camera | Mouse, or I J K L |
| Dash (hold), roll, back in menus | Space |
| Attack / strong attack | Left click / Shift + left click |
| Guard / parry | Right click / Left Ctrl |
| Two-hand | F |
| Use item | R |
| Interact, confirm | E or Enter |
| Lock on | Q or middle click |
| Tool belt | G |
| Menu | Escape |
| Switch spells, items and weapons | Arrow keys, mouse wheel |
| Free the mouse | F1 |
| Fullscreen | Alt+Enter |

In menus the mouse pointer selects what it points at, the left button confirms and the right button goes back. Every key can be changed in the game: SETTINGS > PC > Key Bindings.

Your character's name is typed into a box in the game's window. With a controller the box shows a keyboard: the d-pad moves, A types, X erases and Menu confirms.
