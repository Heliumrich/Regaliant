# How to report a bug

[Back to the main page](../README.md)

1. Check the [known issues](known-issues.md) first.
2. In the launcher, click **Open logs**. It opens the logs folder with the newest session's folder selected. Zip that folder, together with `launcher.log`. For a problem with the shader preparation, zip the whole logs folder: it has a folder for each of its steps. Logs leave out your user name, your computer's name and your profile folder.
3. Open a [bug report](https://github.com/SulphurS16/Regaliant/issues/new?template=bug_report.yml). Say what happened and where, add your PC's specs and attach the zip.

Ideas are welcome too: open a [feature request](https://github.com/SulphurS16/Regaliant/issues/new?template=feature_request.yml). For questions and help, ask on the [Discord](https://discord.gg/rSr5JhxxtZ).

Please don't share game files, keys, decrypted files or download links in issues.
